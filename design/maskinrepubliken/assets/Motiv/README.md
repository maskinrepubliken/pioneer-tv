# Motiv

De tre släktena — årsringar, stammar och rötter — ritade som de står i den visuella guiden. Allt är cirklar och rundade ändar, och linjen avtar där formen tunnar ut.

Ett motiv per yta. Aldrig två i samma ögonkast, aldrig bakom löpande text, aldrig uttonat.
